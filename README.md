# CareerPath AI

An AI-powered platform that analyzes resumes using NLP and generates personalized, week-by-week learning roadmaps to help students and professionals close their skill gaps for software development roles.

**Live Demo:** [Frontend](https://careerpath-ai-frontend-b8y8pjc3o-c-05f1.vercel.app) | [Backend API Docs](https://careerpath-ai-backend-801v.onrender.com/docs)

> Note: The backend is hosted on Render's free tier, so the first request after inactivity may take 30–50 seconds to respond while the server spins up.

---

## Features

- **Resume Upload** — Upload a resume in PDF format directly from the browser
- **AI-Powered Skill Gap Analysis** — Extracts resume content and uses Google's Gemini AI to identify missing skills for a software developer role
- **Personalized Learning Roadmap** — Generates a detailed, week-by-week learning plan based on the identified skill gaps
- **Simple, Clean UI** — Built with React for a fast and responsive experience

---

## How It Works

1. User uploads their resume (PDF) through the frontend
2. The backend extracts the raw text from the PDF using `pdfplumber`
3. The extracted text is sent to Google's Gemini AI with a prompt asking it to identify skill gaps for a software developer role
4. The identified skill gaps are displayed to the user
5. The user can then request a personalized 8-week learning roadmap based on those gaps, also generated by Gemini AI

---

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/` | Health check |
| POST | `/upload-resume` | Upload a resume (PDF) and receive an AI-generated skill-gap analysis |
| POST | `/generate-roadmap` | Submit skill gaps and receive a personalized week-by-week learning roadmap |

Full interactive API documentation is available at `/docs` (Swagger UI).

## Running Locally

### Backend

```bash
git clone https://github.com/dhruvdhaulakhandi/careerpath-ai-backend.git
cd careerpath-ai-backend
python -m venv venv
venv\Scripts\activate      # Windows
pip install -r requirements.txt
```

Create a `.env` file in the root directory:
```
GEMINI_API_KEY=your_gemini_api_key_here
```

Run the server:
```bash
uvicorn main:app --reload
```

Backend will be available at `http://127.0.0.1:8000`

### Frontend

```bash
git clone https://github.com/dhruvdhaulakhandi/careerpath-ai-frontend.git
cd careerpath-ai-frontend
npm install
npm run dev
```

Frontend will be available at `http://localhost:5173`

> Update the API URL in `src/App.jsx` to point to your local backend (`http://127.0.0.1:8000`) if running both locally.
